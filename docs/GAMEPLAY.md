# Gameplay Overview

## Core Objective
The player is rewarded for cleaning up the environment. Every trash item collected increases their trash count and grants XP.

## Progression System
Players gain experience by picking up trash. Level requirements scale upward as the player advances.

### Example progression
- Level 1: Requires 120 XP
- Level 2: Requires ~210 XP
- Level 3: Requires ~315 XP
- Level 4: Requires ~435 XP

This creates a steady progression curve that encourages continued play.

## How the Prototype Works
- Trash objects spawn randomly around the map
- Each item has a value and visual color
- Touching a trash item gives XP and increments the collected count
- XP is converted into level progress in the leaderstats folder
- A HUD shows the current level, collected trash, and XP bar

## Expansion Ideas
To turn this into a richer game, you can add:
- trash bins with rewards for deposit points
- upgrade shops
- daily objectives
- leaderboard competition
- cosmetic unlocks
- timed challenge rounds
- team versus mode

## Recommended Next Features
1. Add a visual trash bin that gives bonus rewards when filled
2. Add a daily objective UI
3. Add sound effects for pickups and level-ups
4. Add a small map with roads and obstacles
5. Add a shop where players spend coins on tools or cosmetics
